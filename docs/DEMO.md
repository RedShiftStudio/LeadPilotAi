# DEMO_MODE
Однократный seed при `--migrate` создаёт организацию «Студия Север», владельца (учётные данные из DEMO_EMAIL/DEMO_PASSWORD), три канала и диалога. В DEMO_MODE исходящие ответы не отправляются на реальные платформы. При отсутствии LLM_API_KEY AI-предпросмотр отвечает 503; загрузка и ручной поиск доступны.
