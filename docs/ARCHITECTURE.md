# Архитектура LeadPilot AI
ASP.NET API авторизует пользователей, проверяет OrganizationId и хранит контакты/лиды/диалоги в PostgreSQL. Интеграционный адаптер отправляет ответы через HTTP API платформ; секреты каналов шифруются AES-GCM. AI-service доступен только внутри Docker, проверяет внутренний токен и организацию, хранит документные фрагменты в pgvector. Браузер никогда не получает LLM_API_KEY. Redis развёрнут, но не используется для очереди в этой версии.
